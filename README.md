# 教材ライブラリ

技術の全体像から基本設計まで学ぶ日本語教材です。ビルド不要の静的HTMLで構成します。

## 公開先

GitHub Pagesでの教材URLです。反映にはmainブランチへのpushとPagesのビルド・公開成功が必要です。

- 教材一覧: https://ta-yokoi.github.io/android-learning-guide/
- Android: https://ta-yokoi.github.io/android-learning-guide/android/
- 組み込み開発: https://ta-yokoi.github.io/android-learning-guide/embedded/
- GoFデザインパターン: https://ta-yokoi.github.io/android-learning-guide/design-patterns/
- 動く図で学ぶGoF: https://ta-yokoi.github.io/android-learning-guide/pattern-animations/
- CSS Motion Gallery: https://ta-yokoi.github.io/android-learning-guide/works/css-motion-gallery/
- 光の潮汐: https://ta-yokoi.github.io/android-learning-guide/works/luminous-tides/
- Kinetic Observatory: https://ta-yokoi.github.io/android-learning-guide/works/kinetic-observatory/
- 作品一覧: https://ta-yokoi.github.io/android-learning-guide/works/

## 構成

```
index.html           # 教材と作品集の入口
works/index.html     # 作品一覧（各作品への親ページ）
android/index.html   # Android（30章・図38点・78問）
embedded/index.html  # 組み込み開発（13章・図21点・52問・用語85語）
design-patterns/index.html # GoF（28章・23パターン・図23点・確認問題46問）
pattern-animations/index.html # 動くGoF図解（5パターン・9シナリオ・確認問題5問）
works/css-motion-gallery/index.html # HTMLだけで動くアニメーション集（9作品）
works/luminous-tides/index.html # 光の潮汐：三層の光の流れの独立作品
works/kinetic-observatory/index.html # 光粒子だけで描く12種類の立体変形
tools/generate_kinetic_observatory.py # 新作の座標とHTMLを再生成する開発用スクリプト（閲覧時は不要）
.nojekyll
```

各教材はCSS・SVGなどを内包するHTMLです。体系学習ガイドは操作用JavaScriptを内包し、動くGoF図解・CSS Motion Gallery・Kinetic ObservatoryはHTMLとCSSだけで構成します。外部のスクリプト・画像・フォントは不要です。
出典のリンク先を開く場合はインターネット接続が必要です。

## 公開と追加

GitHub Pagesの公開元がmainブランチの/(root)なら、この構成をリポジトリ直下へ配置してpushします。
Pagesのビルド・公開に成功した後にサイトへ反映されます。
github-pagesという親フォルダ自体はアップロードしません。ZIPを使う場合は中身を配置します。
新ジャンルは<genre>/index.htmlを追加し、教材一覧へ相対リンクのカードを追加します。

## 読了記録

Androidはandroid16-learning-guide-completed-v1、組み込み開発はembedded-learning-guide-completed-v1を使います。
GoFはgof-design-patterns-learning-guide-completed-v1を使います。
同じブラウザ・公開元のlocalStorageに保存し、教材ごとの記録を分離します。
端末間・ブラウザ間では同期しません。保存できない環境では閲覧中のみ保持します。

## 確認範囲

HTML構造・リンク・図・操作ロジックとPC向けコードを検証しました。
実ブラウザ・実スマートフォンでの表示、実機・BSP・電気信号・電源・更新動作は別途確認が必要です。
教材本文と巻末に適用条件・未検証の範囲を記載しています。
GitHub Pagesへの反映はpush後のビルド・公開結果で確認します。

## 外観の自動切替

教材一覧・Android・組み込み開発・GoFデザインパターン・動くGoF図解は、端末／ブラウザの外観設定に応じてライト・ダークを自動切替します。
CSSのprefers-color-schemeを使い、本文・図・表・フォームを切替します。設定の保存や追加ライブラリは不要です。
印刷では既存の明るい配色を使います。実端末での表示確認は別途必要です。

## 動く図で学ぶGoFデザインパターン

`pattern-animations/index.html`は、JavaScriptを使わずCSSだけで要求・委譲・通知・戻りを動かす単一HTMLです。

方策の選択、購読解除の有無、ラッパーの順序、CSV／JSONの生成フックを含む9つの説明シナリオがあります。

## Kinetic Observatory — 光の粒子の立体変形

`works/kinetic-observatory/index.html`は、360個の丸い光粒子だけで立体を描く単一HTML作品です。球体・六弁花冠・トーラス・三葉結び目・メビウスの帯・二重らせん・星芒・立方体・五重結び目・四次元トーラスの投影・絡み合う二重環・ローレンツ軌道の12形状へ96秒で変形します。各形を約4秒保ち、次の形へ約4秒で移動します。形を保つ間も全体が12秒で1回転します。奥行きと視点の計算は作成時に行います。変形区間には2つの中間座標を追加し、粒子が3つの流れに分かれて広がり、ねじれて再集合します。粒の大きさ・色・輝きの違いと遠近感で形を見せます。

トップの「作品集」から作品一覧を開いて選ぶか、CSS Motion Galleryの「立体実験室」から開けます。一時停止・視点・粒子密度の切替、キーボード操作、動きを減らす設定と印刷に対応します。間引いた粒子はアニメーションを停止し、密度を戻すと初期位相から再開します。JavaScript・外部素材・追加パッケージは不要です。

開発時は `python3 tools/generate_kinetic_observatory.py` で座標とHTMLを再生成できます。Pythonは標準ライブラリのみ使用し、閲覧時は不要です。生成時に各形の座標の有限性・重複・半径の上限を検証します。

## 光の潮汐 / Luminous Tides

## 粒子の奥行き表現と連続再生の負荷対策

粒子の奥行きに応じた拡縮・不透明度は、HTML生成時に `tools/particle_depth.py` で計算します。再生時に使うのは通常のCSS `transform` と `opacity` のアニメーションです。毎フレーム更新する型付きカスタムプロパティと、視点行列のCSS計算を取り除きました。初期表示は粒子の立体変形180粒、光の潮汐192粒です。「軽量表示」を外すと最大360粒／384粒になります。ぼかした発光も一部の粒に限定しています。間引きでは粒子を `display:none` にして描画とアニメーションを停止するため、密度を戻すと追加粒子は初期位相から再開します。

奥行きの前後関係は固定視点で作成時に算出し、全体の回転は画面に向いた軸で行います。これにより手前／奥の大小・透明度を保ちながら回転します。視点を切り替えると、粒子と場面表示は初期位相から再開します。旧方式の検証では、光の潮汐の描画プロセスのRSSが75秒で約944MBから4,706MBへ増加しました。ユーザーの端末でのクラッシュ自体は再現できていません。

高密度（360粒／384粒）を2ページ同時に120秒再生し、Chromiumのクラッシュ・ページエラーがないことと、再生後の停止操作を確認しました。描画プロセスのRSSは最大約465MBでした。初期の軽量表示（180粒／192粒）でも2作品を120秒連続再生し、クラッシュとページエラーはありませんでした。描画プロセスのRSSは最大約321MBでした。この結果は検証環境のChromiumでのもので、報告端末での再現条件は再生約1分という情報のみです。
