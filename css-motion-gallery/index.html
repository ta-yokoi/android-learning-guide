09

Constellation

光が、秩序を見つける。

480個の光点が、それぞれの軌道をたどって立体をつくる。球体から輪へ、輪から二重らせんへ。形を保つ静かな時間と、大きくほどける時間を交互に眺める作品です。

動きのしくみを見る

各光点に、散開・球体・トーラス・二重らせん・立方体の5組のXYZ座標を埋め込み、translate3dをCSSで補間しています。480点の変形周期は36秒、集合体の回転周期は42秒なので、周回ごとに見る角度が変わります。JavaScriptや外部ライブラリは使いません。多数の発光要素を描くため、端末によって滑らかさは異なります。

.particle-camera { perspective: 900px; }
.particle-rotor { transform-style: preserve-3d; }
.photon { animation: photon-morph 36s infinite; }
/* 各光点には形ごとの座標を設定 */
@keyframes photon-morph {
  18%, 26% { transform: translate3d(var(--x1),var(--y1),var(--z1)); }
  38%, 46% { transform: translate3d(var(--x2),var(--y2),var(--z2)); }
}
AURORA
STUDY / 01LIGHT / GRADIENT / 18–27s
01

Aurora

漂う、光の幕。

重なり合う緑と紫の光が、夜空をゆっくり横切る。山の輪郭と星は静止し、光の層だけが呼吸するように動きます。

動きのしくみを見る

半透明のグラデーションを3層重ね、ぼかしは固定したまま位置・角度・横幅を変えています。周期をずらすことで、同じ動きの繰り返しを目立たなくします。

CSSの抜粋。ページ全体は1つのHTMLで完結しています。

.stage-aurora .art { perspective: 900px; transform-style: preserve-3d; }
.aurora-ribbon {
  filter: blur(34px);
  animation: aurora-drift 18s linear infinite;
}
@keyframes aurora-drift {
  50% { transform: translate3d(4%, 13%, var(--depth)) rotateX(-8deg) rotateZ(-6deg) scaleX(1.12); }
}

02

Orbital poetry

静かな引力。

傾いた軌道を巡る、小さな光。中心の球体と異なる速さの衛星が、奥行きのあるリズムをつくります。

動きのしくみを見る

円形の要素を回転させ、その端に置いた点を公転させます。親要素をX軸方向に傾けると軌道が楕円に見えます。実際の天体運動のシミュレーションではありません。

CSSの抜粋。ページ全体は1つのHTMLで完結しています。

.orbital-system { transform-style: preserve-3d; }
.orbit-axis { transform: rotateX(67deg) rotateZ(-25deg) translateZ(25px); }
.satellite-orbit { animation: orbit-spin 15s linear infinite; }
.orbit-core { box-shadow: inset -13px -16px 20px #071b16b5, 0 20px 32px #0009; }

STUDY / 03PERSPECTIVE / 3D / 24s
03

Folded space

平面から、立体へ。

6枚の透明な面が組み上がり、ひとつの立方体になる。回転するたびに、線と面の重なりが新しい表情を見せます。

動きのしくみを見る

6面をtranslateZと90度単位の回転で配置し、親にtransform-style: preserve-3dを指定しています。外側のperspectiveで遠近感を与えます。

CSSの抜粋。ページ全体は1つのHTMLで完結しています。

.cube {
  transform-style: preserve-3d;
  animation: cube-turn 24s linear infinite;
}
.front { transform: translateZ(62px); }
.right { transform: rotateY(90deg) translateZ(62px); }
STUDY / 04PHASE / SCALE / 4.8s
04

Wave field

少しずつ、ずれる。

同じ動きに、小さな時間差を。36本の線が伸び縮みするだけで、横へ伝わる波が生まれます。

動きのしくみを見る

各線は同じscaleYのキーフレームを使います。animation-delayを少しずつ負にして開始位置をずらし、画面を開いた瞬間から波形が続いている状態を作ります。音声には連動しません。

CSSの抜粋。ページ全体は1つのHTMLで完結しています。

.stage-wave { perspective: 800px; }
.wave-field { transform: rotateX(55deg) rotateZ(-16deg) translateZ(72px); }
.wave-bar { animation: wave-pulse 4.8s ease-in-out infinite;
  animation-delay: calc(var(--i) * -.14s); }
@keyframes wave-pulse {
  50% { transform: translateZ(46px) scaleY(1); }
}
STUDY / 05BORDER RADIUS / BLEND / 16–25s
05

Liquid silk

ほどける、かたち。

輪郭の違う3つの色面が、重なっては離れる。半透明の膜のような、やわらかな質感を楽しめます。

動きのしくみを見る

border-radiusの横方向・縦方向を別々に指定し、輪郭を変化させています。mix-blend-mode: screenで重なる部分を明るくし、移動と回転を添えます。流体計算は行っていません。

CSSの抜粋。ページ全体は1つのHTMLで完結しています。

.liquid-art { perspective: 750px; transform-style: preserve-3d; }
.liquid-shape {
  mix-blend-mode: screen;
  animation: liquid-morph 16s ease-in-out infinite;
}
@keyframes liquid-morph {
  50% { transform: translate3d(18px, -10px, var(--depth)) rotateY(22deg) rotateZ(25deg) scale(1.05); }
}

STUDY / 06TYPOGRAPHY / LOOP / 26–32s
06

Type in motion

文字にも、リズムを。

塗りの文字と、輪郭だけの文字。逆方向に流れる2本の帯が、言葉をグラフィックへ変えていきます。

動きのしくみを見る

同じ文字列を2回並べた帯全体を、横幅の半分だけ移動させます。終端が開始時と同じ見た目になるため、途切れないループを作れます。

CSSの抜粋。ページ全体は1つのHTMLで完結しています。

.stage-type { perspective: 760px; }
.type-art { transform: rotateY(-23deg) rotateX(16deg) rotateZ(-7deg); }
.type-track { animation: type-slide 26s linear infinite; }
@keyframes type-slide { to { transform: translateX(-50%); } }
STUDY / 07MASK / RADIAL LIGHT / 18–50s
07

Quiet eclipse

暗さが、光を描く。

暗い円の縁から、細い金色の光がこぼれる。ゆっくり回る光冠と、ごく小さな位置の変化で、静かな日食を表現します。

動きのしくみを見る

光る円の上に暗い円を重ね、数pxだけ移動させます。光冠には円すい形グラデーションと放射状マスクを使っています。天文学的な軌道や縮尺を再現したものではありません。

CSSの抜粋。ページ全体は1つのHTMLで完結しています。

.stage-eclipse .art { perspective: 850px; }
.sun { transform: translateZ(-35px); }
.moon { animation: moon-drift 18s ease-in-out infinite; }
@keyframes moon-drift {
  50% { transform: translate3d(3px, 5px, 80px); }
}
STUDY / 08SCALE / DEPTH / 16s
08

Infinite room

奥へ、また奥へ。

ひとつの消失点から、枠が静かに広がる。回転と拡大の組み合わせが、終わりのない空間をつくります。

動きのしくみを見る

10枚の枠を同じ中心に置き、開始時刻をずらして拡大・回転させます。最初と最後で透明にすることで、ループが巻き戻る瞬間を隠しています。

CSSの抜粋。ページ全体は1つのHTMLで完結しています。

.stage-tunnel .art { perspective: 760px; }
.tunnel-frame { animation: tunnel-depth 16s linear infinite;
  animation-delay: calc(var(--i) * -1.6s); }
@keyframes tunnel-depth {
  0% { transform: translateZ(-600px) scale(.35); opacity: 0; }
  12%, 75% { opacity: .6; }
  100% { transform: translateZ(450px) rotateZ(75deg) scale(1.3); opacity: 0; }
}

動きを眺める。
しくみをほどく。

右上のボタンで作品ごとに一時停止できます。画面下のボタンは全体の停止・解除です。全体の停止を解除しても、個別に停止した作品は止まったままになります。

「動きのしくみを見る」を開くと、表現の仕組みとCSSの抜粋を読めます。作品はCSSの決められた動きで構成しており、物理シミュレーションや音声解析は行っていません。

  • キーボードのTabで操作部品へ移動し、Spaceで停止・解除できます。
  • 端末の「動きを減らす」設定では静止表示になります。
  • 外部の画像・フォント・動画やJavaScriptを使わず、HTML内のCSSだけで描画しています。
  • 印刷時は全作品を静止表示します。色はブラウザの背景印刷設定に従います。
