## 公開と追加

GitHub Pagesの公開元がmainブランチの/(root)なら、この構成をリポジトリ直下へ配置してpushします。
Pagesのビルド・公開に成功した後にサイトへ反映されます。
github-pagesという親フォルダ自体はアップロードしません。ZIPを使う場合は中身を配置します。
教材は<分野>/<形式>/index.htmlを追加し、<分野>/index.htmlへカードを追加します。新しい分野はトップにも入口を追加します。作品はworks/<name>/index.htmlを追加し、works/index.htmlへカードを追加します。

## 読了記録

Androidはandroid16-learning-guide-completed-v1、組み込み開発はembedded-learning-guide-completed-v1を使います。
GoFはgof-design-patterns-learning-guide-completed-v1を使います。
同じブラウザ・公開元のlocalStorageに保存し、教材ごとの記録を分離します。
端末間・ブラウザ間では同期しません。保存できない環境では閲覧中のみ保持します。

## 外観の自動切替

教材一覧・Android・組み込み開発・GoFデザインパターン・動くGoF図解は、端末／ブラウザの外観設定に応じてライト・ダークを自動切替します。

## 動く図で学ぶGoFデザインパターン

`gof/animations/index.html`は、JavaScriptを使わずCSSだけで要求・委譲・通知・戻りを動かす単一HTMLです。
Strategy、Observer、Decorator、State、Factory Methodの5パターンを収録します。
方策の選択、購読解除の有無、ラッパーの順序、CSV／JSONの生成フックを含む9つの説明シナリオがあります。
図と番号付きの説明、役割、省略事項、誤解しやすい点、解答を開閉できる確認問題5問を備えます。

トップの「GoFデザインパターン」から教材形式を選ぶか、`gof/animations/index.html`をブラウザで直接開きます。
HTTPサーバーを利用する場合は上記の起動コマンドで http://localhost:8000/gof/animations/ を開きます。
各図は初期停止で、「再生する」のチェックを外すとその位置で一時停止します。図ごとの操作は独立し、シナリオの切替先は初めから開始します。
動きは業務処理の実行ではなく、あらかじめ決めた説明の再生です。

外部リソース・JavaScript・ビルド工程・追加パッケージは不要です。
狭い画面では図の中だけを横スクロールできます。動きを減らす設定では静止した矢印と手順で読みます。
ブラウザの印刷機能では全シナリオと解答を静止表示します。読了記録は保存しません。

## Kinetic Observatory — 光の粒子の立体変形

`works/kinetic-observatory/index.html`は、360個の丸い光粒子だけで立体を描く単一HTML作品です。球体・六弁花冠・トーラス・三葉結び目・メビウスの帯・二重らせん・星芒・立方体・五重結び目・四次元トーラスの投影・絡み合う二重環・ローレンツ軌道の12形状へ96秒で変形します。各形を約4秒保ち、次の形へ約4秒で移動します。形を保つ間も全体が12秒で1回転します。奥行きと視点の計算は作成時に行います。形状間の対応を空間的に近づけ、滑らかな加減速で直接次の形へ移ります。粒の大きさ・色・輝きの違いと遠近感で形を見せます。

トップの「作品集」から作品一覧を開いて選ぶか、CSS Motion Galleryの「立体実験室」から開けます。一時停止・視点・粒子密度の切替、キーボード操作、動きを減らす設定と印刷に対応します。間引いた粒子はアニメーションを停止し、密度を戻すと初期位相から再開します。JavaScript・外部素材・追加パッケージは不要です。

開発時は `python3 tools/generate_kinetic_observatory.py` で座標とHTMLを再生成できます。Pythonは標準ライブラリのみ使用し、閲覧時は不要です。生成時に各形の座標の有限性・重複・半径の上限を検証します。

閲覧はHTMLを直接開くか、リポジトリ直下で `python3 -m http.server 8000` を実行し http://localhost:8000/works/kinetic-observatory/ を開きます。

ブラウザ検証はローカルHTTP経由です。この環境のChromeではfile://が管理ポリシーで制限されています。実スマートフォンのフレームレート、Safari／Firefox、実プリンターは未確認です。

## 光の潮汐 / Luminous Tides

`works/luminous-tides/index.html`は既存作品と独立した新作です。384個の丸い光粒子が、青緑・琥珀・菫色の三本の幅を持つ帯を描きます。粒子は23秒・29秒・37秒の周期で軌道を巡り、琥珀の流れだけが逆方向へ進みます。帯の膨張・収縮は11秒・13秒・17秒、全体の回転は36秒。異なる周期の重なりで、奥行きと隙間が変わり続けます。

トップの「作品集」から作品一覧を開いて選ぶか、HTMLを直接開きます。HTTPではリポジトリ直下で `python3 -m http.server 8000` を実行し http://localhost:8000/works/luminous-tides/ を開きます。各色の帯の表示、粒子の間引き（192粒）、一時停止に対応します。色の層の切替では時間を保ちます。密度を戻すと、間引いていた粒子は初期位相から再開します。動きを減らす設定と印刷では静止します。

## 粒子の奥行き表現と連続再生の負荷対策
