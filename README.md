# 教材ライブラリ

技術の全体像から基本設計まで学ぶ日本語教材です。ビルド不要の静的HTMLで構成します。

## 公開先

GitHub Pagesでの教材URLです。反映にはmainブランチへのpushとPagesのビルド・公開成功が必要です。

- 教材一覧: https://ta-yokoi.github.io/android-learning-guide/
- Android: https://ta-yokoi.github.io/android-learning-guide/android/
- 組み込み開発: https://ta-yokoi.github.io/android-learning-guide/embedded/
- GoFデザインパターン: https://ta-yokoi.github.io/android-learning-guide/design-patterns/
- 動く図で学ぶGoF: https://ta-yokoi.github.io/android-learning-guide/pattern-animations/
- CSS Motion Gallery: https://ta-yokoi.github.io/android-learning-guide/css-motion-gallery/

## 構成

```
index.html           # 教材一覧
android/index.html   # Android（30章・図38点・78問）
embedded/index.html  # 組み込み開発（13章・図21点・52問・用語85語）
design-patterns/index.html # GoF（28章・23パターン・図23点・確認問題46問）
pattern-animations/index.html # 動くGoF図解（5パターン・9シナリオ・確認問題5問）
css-motion-gallery/index.html # HTMLだけで動くアニメーション集（9作品）
.nojekyll
```

各教材はCSS・SVGなどを内包するHTMLです。体系学習ガイドは操作用JavaScriptを内包し、動くGoF図解とCSS Motion GalleryはHTMLとCSSだけで構成します。外部のスクリプト・画像・フォントは不要です。
出典のリンク先を開く場合はインターネット接続が必要です。

## 公開と追加

GitHub Pagesの公開元がmainブランチの/(root)なら、この構成をリポジトリ直下へ配置してpushします。
Pagesのビルド・公開に成功した後にサイトへ反映されます。
github-pagesという親フォルダ自体はアップロードしません。ZIPを使う場合は中身を配置します。
新ジャンルは<genre>/index.htmlを追加し、教材一覧へ相対リンクのカードを追加します。

## 読了記録

Androidはandroid16-learning-guide-completed-v1、組み込み開発はembedded-learning-guide-completed-v1を使います。
GoFはgof-design-patterns-learning-guide-completed-v1を使います。
同じブラウザ・公開元のlocalStorageに保存し、教材ごとの記録を分離します。
端末間・ブラウザ間では同期しません。保存できない環境では閲覧中のみ保持します。

## 確認範囲

HTML構造・リンク・図・操作ロジックとPC向けコードを検証しました。
実ブラウザ・実スマートフォンでの表示、実機・BSP・電気信号・電源・更新動作は別途確認が必要です。
教材本文と巻末に適用条件・未検証の範囲を記載しています。
GitHub Pagesへの反映はpush後のビルド・公開結果で確認します。

## 外観の自動切替

教材一覧・Android・組み込み開発・GoFデザインパターン・動くGoF図解は、端末／ブラウザの外観設定に応じてライト・ダークを自動切替します。
CSSのprefers-color-schemeを使い、本文・図・表・フォームを切替します。設定の保存や追加ライブラリは不要です。
印刷では既存の明るい配色を使います。実端末での表示確認は別途必要です。

## GoFデザインパターン教材

生成5・構造7・振る舞い11の全23パターンを、問題、変更要求、適用前後のJavaコード、設計図、利点・コスト・不採用の判断から学びます。
導入、類似パターンの比較、注文通知システムの総合演習、用語集22語、参考資料を含む28章です。
クラスとインターフェースの基礎が前提です。Java 17を基準とし、各コード例は独立したMain.javaとしてJDK 17以降で実行できます。

閲覧はルートのindex.htmlから教材カードを選ぶか、design-patterns/index.htmlをブラウザで開きます。
HTTPで確認する場合はリポジトリ直下で次を実行し、http://localhost:8000/design-patterns/ を開きます。

```sh
python3 -m http.server 8000
```

目次、章間移動、解答の開閉、設計図の拡大、章ごとの読了記録に対応します。
印刷ボタンでは解答も展開します。CSS・SVG・JavaScriptはHTML内に含め、教材自体は外部リソースに依存しません。
実用上の例外処理・並行性・永続化・配送保証の限界は各章と巻末に明記しています。

### GoF教材の検証結果

- 掲載HTMLから抽出した47例（適用前23・適用後23・総合演習1）をJDK 17の`javac --release 17`でコンパイルし、実行しました。適用後23例と総合演習は掲載した出力とも照合済みです。
- Chromiumで幅1440・390・320px、ライト／ダーク表示を確認しました。ページ全体の横はみ出しはなく、コードと拡大図は領域内で横スクロールできます。
- 一覧との相互リンク、章内リンク、解答のキーボード開閉、図の表示切替、読了記録の再読込を確認しました。保存不可・不正な保存データの場合も操作を継続できます。
- 既存Android／組み込み教材の表示と読了記録の分離、JavaScript無効時の閲覧、印刷時の解答展開と白背景を確認しました。教材内リンク切れ・JavaScript実行エラーはありません。ローカルサーバーのfavicon.icoは未配置で、ブラウザの自動取得のみ404になります。
- 参考資料の外部リンクはHTTP応答を確認しました。出版社のリンクは検索ページへ転送される場合があります。
- 実スマートフォン、Safari／Firefox、実プリンターは未確認です。公開時はGitHub Pagesのデプロイ完了と教材URLへの到達を別途確認します。

## 動く図で学ぶGoFデザインパターン

`pattern-animations/index.html`は、JavaScriptを使わずCSSだけで要求・委譲・通知・戻りを動かす単一HTMLです。
Strategy、Observer、Decorator、State、Factory Methodの5パターンを収録します。
方策の選択、購読解除の有無、ラッパーの順序、CSV／JSONの生成フックを含む9つの説明シナリオがあります。
図と番号付きの説明、役割、省略事項、誤解しやすい点、解答を開閉できる確認問題5問を備えます。

ルートの教材カードを選ぶか、`pattern-animations/index.html`をブラウザで直接開きます。
HTTPサーバーを利用する場合は上記の起動コマンドで http://localhost:8000/pattern-animations/ を開きます。
各図は初期停止で、「再生する」のチェックを外すとその位置で一時停止します。図ごとの操作は独立し、シナリオの切替先は初めから開始します。
動きは業務処理の実行ではなく、あらかじめ決めた説明の再生です。

外部リソース・JavaScript・ビルド工程・追加パッケージは不要です。
狭い画面では図の中だけを横スクロールできます。動きを減らす設定では静止した矢印と手順で読みます。
ブラウザの印刷機能では全シナリオと解答を静止表示します。読了記録は保存しません。

### 動くGoF図解の検証結果

- ChromiumのJavaScriptを無効にして、全9シナリオの各工程で移動する印と非表示でのリセットを確認しました。初期停止、図ごとの独立再生、停止位置の保持、シナリオ切替の初期化も確認済みです。
- キーボードでのチェックボックス・ラジオボタン・解答開閉・図の横スクロールを確認しました。
- 幅1440・390・320pxのライト／ダークでページ全体の横はみ出しがないこと、動きを減らす設定でアニメーションがなく手順が読めることを確認しました。
- 印刷用PDFで全9シナリオと5問の解答の表示、操作部品とアニメーションの非表示、白背景を確認しました。
- 教材一覧との相互リンクと既存GoF教材への章リンクを確認しました。教材内にscriptや外部リソース参照はなく、閲覧時も外部への通信はありません。
- この環境のChromeはfile://の閲覧を管理ポリシーで制限しているため、ブラウザ検証はローカルHTTP経由です。直接ファイルを開く環境、実スマートフォン、Safari／Firefox、実プリンターは未確認です。

## CSS Motion Gallery — HTMLだけで動くアニメーション集

`css-motion-gallery/index.html`は、9つのCSSアニメーション作品を収録した単一HTMLのギャラリーです。
オーロラ、軌道運動、3Dキューブ、波、液体グラデーション、動く文字、日食、無限トンネルを、外部画像や動画を使わずに描きます。各作品に遠近感、前後の層、陰影を加えています。
CSSをHTML内に含め、JavaScript・外部ライブラリ・CDN・外部フォント・ビルド工程は不要です。

ルートの教材一覧から「CSS Motion Gallery」を選ぶか、`css-motion-gallery/index.html`をブラウザで開きます。
HTTPサーバーを利用する場合は、リポジトリ直下で`python3 -m http.server 8000`を実行し、http://localhost:8000/css-motion-gallery/ を開きます。

全体の一時停止と作品ごとの一時停止に対応します。端末の「動きを減らす」設定では静止表示になります。
スマートフォン表示と印刷にも対応し、読了記録は保存しません。
作品の光や色を見せるため、このギャラリーは暗い配色を基本とします。既存の教材一覧や体系学習ガイドの自動ライト／ダーク切替とは独立した外観です。

### CSS Motion Galleryの検証結果

ChromiumでJavaScriptを無効にし、8作品すべての動き、全体／個別停止と再開、キーボード操作、幅1440・768・390・320pxでの表示、動きを減らす設定、印刷、一覧との相互リンクを確認しました。外部リソースへの通信とJavaScript実行エラーはありません。
この環境ではfile://が管理ポリシーで制限されるため、検証はローカルHTTP経由です。直接ファイルを開く環境、実スマートフォン、Safari／Firefox、実プリンターは未確認です。

### Constellation：480光点の立体変形

CSS Motion Galleryに9作目を追加。480点が散開・球体・トーラス・二重らせん・立方体へ36秒周期で変形し、集合体は42秒周期で回転します。座標はHTML内に保持し、実行時JavaScriptは不要です。全体／個別停止と動きを減らす設定に対応します。端末によって描画負荷が異なります。

追加後、JavaScript無効のChromiumで全9作品の動き、全体／個別停止、幅1440・768・390・320px、動きを減らす設定、印刷、一覧リンクを確認しました。実スマートフォンでのフレームレートは未測定です。

### 既存8作品の立体構造の追加

オーロラ72フィラメント、軌道96点、立方体96節点、波面81点、流体96点、文字36字、日食96光条、トンネル72点を追加。作品ごとに異なる構造・位相差・変形・回転を組み合わせています。すべてHTML内のCSSで動作します。
