PARTICLE MORPH / 光の粒子だけで描く

光が、かたちになる。

720個の光が、球から花冠へ、結び目かららせんへ。
8つの立体を巡り、色と輝きをゆっくり変える粒子の彫刻。

「動きを減らす」設定に合わせて球体を静止表示しています。視点と粒子密度は切り替えられます。

HTML + CSS / 音声なし
01 / 形

粒子だけで、8つの立体。

球体、六弁花冠、トーラス、三葉結び目、メビウスの帯、二重らせん、星芒、立方体。同じ720粒が、それぞれの数式で求めた位置へ移ります。メビウスの帯は半ひねりした曲面、結び目は太さを持つ閉じた軌道です。

02 / 色と奥行き

光の密度が、面をつくる。

粒ごとの大きさ・色・明るさの違いと、前後の距離による遠近感で立体を見せます。視点は限定した角度でゆっくり動き、粒が一斉に真横を向くことを避けています。

03 / 操作

止めて、かたちを観察する。

Tabで操作を選び、Spaceで停止や粒子密度を切り替えます。視点の選択は矢印キーでも操作できます。粒子を半分にしても時間は保たれます。設定は保存しません。

座標とアニメーションのしくみ

8種類のXYZ座標をHTML内に持たせ、CSSのtranslate3d・scale・色・不透明度を補間します。数式の計算は作成時にPython標準ライブラリで行い、閲覧時はHTML内のCSSだけで動作します。生成コマンドは python3 tools/generate_kinetic_observatory.py です。

端末の「動きを減らす」設定と印刷では球体を静止表示します。JavaScript・外部素材・追加パッケージは不要です。滑らかさは端末により異なります。
